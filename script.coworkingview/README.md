# CoworkingView

Program add-on for Kodi. Pick a city and read the current CoworkingView Price Index: median flexible-desk, fixed-desk, private-office, day-pass and meeting-room prices, with the sample size and the CC BY 4.0 attribution.

The add-on calls one public endpoint, `GET https://api.coworkingview.com/v1/market/rates`. There is no account, no advertising, and no tracking. Language and currency are in the add-on settings. City currency leaves each figure in the currency CoworkingView publishes for that city. The city list is the cities that currently have a published product price.

The Price Index data is CC BY 4.0. The add-on code is MIT; see `LICENSE.txt`.
